# Archived React Prototype

This folder contains the original React/Vite UX prototype used during Phases 1–4 as a design reference.

**It is not used in production.** The live dashboard is in `server/` (EJS + HTMX).

To run the prototype locally (optional):

```bash
cd archive/prototype-react
npm install
npm run dev   # http://localhost:5173
```

Do not deploy this to production. All features were ported to `server/views/` and `server/public/`.
